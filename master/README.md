# Master

Research and production inputs for the anatomy models. Distribution copies are built from this tree. The HMC in `distribution/containers/` does not replace these sources.

| Path | Role |
|---|---|
| `knowledge/` | 17-system map, condition map, DICOM organ map, rules, and shapes |
| `research/sources.md` | The external corpora a full male and female atlas has to be built from |
| `research/modelling-requirements.md` | What a finished model has to contain before it is packaged |
| `production/human_anatomy.vibe` | The VibeScript Synth already ran for the current welfare bodies |
| `production/human_authored.vibe` | The VibeScript Synth ran to generate named parts itself |
